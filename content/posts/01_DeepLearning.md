# Deep Learning Vocabulary

## CNN

-   Full Name: Convolutional Neural Network
-   词根: con- together + volv roll + neural
-   中文: 卷积神经网络
-   含义: 利用卷积提取局部特征的神经网络架构。
-   常见搭配:
    -   convolution layer 卷积层
    -   feature extraction 特征提取

## RNN

-   Full Name: Recurrent Neural Network
-   词根: re- again + curr run
-   中文: 循环神经网络
-   含义: 使用循环结构处理序列数据。
-   搭配:
    -   hidden state 隐藏状态
    -   sequence modeling 序列建模

## Transformer

-   词根: transform = change form
-   中文: Transformer架构
-   含义: 基于attention机制的深度学习架构。
