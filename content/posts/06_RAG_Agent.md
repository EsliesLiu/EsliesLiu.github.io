# RAG Agent Vocabulary

## Retrieval

-   词根: retrieve = get back
-   中文: 检索

## Augmentation

-   词根: augment = increase
-   中文: 增强

## Hallucination

-   中文: 幻觉
-   AI含义: 模型生成不存在的信息。

## Reasoning

-   中文: 推理

## Alignment

-   中文: 对齐
-   AI含义: 模型行为与目标一致。
